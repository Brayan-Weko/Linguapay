1. Synthèse Exécutive & Problématique Résolue

Au Cameroun et dans l'ensemble de la zone CEMAC, la digitalisation des services financiers (Mobile Money, portails bancaires, microfinance) connaît une croissance exponentielle. Cependant, plus de 70 % des interfaces utilisateurs demeurent rédigées exclusivement en français ou en anglais, mobilisant un vocabulaire technique souvent hermétique (« Solde créditeur », « Commission de découvert », « Virement irréversible », « Frais de transaction »).

Pour des millions d'utilisateurs dont la langue usuelle d'échange et de confiance est une langue nationale (telles que l'Ewondo au Centre-Sud, le Duala sur le Littoral, ou le Fulfulde dans le Grand Nord), cette fracture linguistique engendre trois risques critiques :

  1. L'Exclusion Financière Numérique : Réticence à utiliser les services dématérialisés par crainte de mal interpréter un libellé ou de valider une opération coûteuse.
  2. La Vulnérabilité aux Fraudes et la Dépendance : Nécessité de confier son smartphone ou son code secret PIN à un intermédiaire pour lire les avertissements bancaires.
  3. Le Risque d'Erreur Transactionnelle : Confusion fréquente entre le montant principal d'un transfert et les frais de service prélevés.
La Réponse LinguaPay : Une couche d'adaptation sécurisée et universelle, fonctionnant sans modifier une seule ligne du code source hôte, capable de s'adapter en direct à n'importe quel site bancaire, de garantir l'invariance mathématique absolue des montants financiers et de fournir une synthèse vocale native pour les personnes analphabètes ou malvoyantes.

3. Le Bouclier Financier Déterministe (`EntityShield`)

L'innovation centrale de LinguaPay réside dans son bouclier mathématique réversible. Contrairement aux traducteurs automatiques génériques qui altèrent les nombres (ex: transformer « 50 000 FCFA » en « 50 dollars » ou modifier un chiffre de téléphone), l'EntityShield neutralise tout risque d'hallucination avant que le texte n'atteigne le moteur linguistique.

5. Pont Universel Multi-Langues & Synthèse Vocale FCFA

Pont Universel vers l'Anglais (`UniversalPivotBridge`)

De nombreux établissements bancaires panafricains ou fintechs internationales disposent de pages conçues en langues étrangères. LinguaPay intègre un module de détection heuristique et scripturale qui pivote automatiquement le texte source vers l'anglais avant de l'adapter dans les langues camerounaises.

Synthèse Vocale & Verbalisation Grammaticale des Nombres (`NumberComposer`)

Pour les populations rurales ou peu scolarisées, l'écriture orthographique des langues nationales peut être difficile à déchiffrer. LinguaPay résout ce problème par un moteur récursif de verbalisation numérique associé à un lecteur séquentiel WebAudio fluide (capsules audio PCM 22 050 Hz avec fondu croisé de 25 ms).

Exemple de verbalisation d'un virement de 51 500 FCFA :
  • En Ewondo : « Dòla mewóm métán ai ewólo ai bikpwele bitán »
  • En Duala : « Moni mw'a mômô matanu na ewólo na bikpwele bitanu »
  • En Fulfulde : « Buuɗi ujune capanɗe jowi e go'o e teemeɗɗe jowi »

8. Procédure de Déploiement & Reproductibilité

Toutes les briques du projet sont immédiatement reproductibles sur n'importe quel poste de travail en quelques commandes :

Option 1 : Démarrage Local Standard

# 1. Démarrer le backend Core API (FastAPI)
cd backend
.\.venv\Scriptsctivate
uvicorn app.main:app --port 8000 --reload

# 2. Compiler l'extension navigateur MV3 (dans un second terminal)
cd extension
npm install
npm run build

# 3. Démarrer le simulateur bancaire SimuBank CM (dans un troisième terminal)
python -m http.server 5173 --directory simulator

Option 2 : Démarrage en Une Ligne via Docker Compose

docker compose up --build

Démarre simultanément le backend Core API sur http://localhost:8000 et le simulateur bancaire sur http://localhost:5173.

Accès aux Interfaces & Documentation

  • Swagger UI Interactif : http://localhost:8000/docs (test en direct de toutes les routes).
  • Documentation ReDoc : http://localhost:8000/redoc.
  • Simulateur Bancaire SimuBank CM : http://localhost:5173/index.html.
